# Payment Options (Demo)

## Sharing payment links
- For demos, a payment link can be shared via WhatsApp/SMS/email.
- The link should include the amount and a reference so payment can be reconciled.

## Promise-to-pay (PTP)
- If the customer cannot pay immediately, capture a specific date (YYYY-MM-DD preferred).
- If they cannot commit to a date, capture a callback time.
